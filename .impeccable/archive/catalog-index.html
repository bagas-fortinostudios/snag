What this actually is

A free way to save videos from Instagram, TikTok and YouTube onto your own Mac. You set it up once, then it is one short line every time.

yt-dlp
Fetches the video from the site. It is the part that actually does the downloading.
ffmpeg
Joins the picture and the sound into one finished file, and converts it when you want a different format.
Snag
The short command that runs both of them for you. On their own they need a long line of settings that changes from site to site, and it is easy to get wrong. Snag reads your link, picks the right settings, and does the whole job in one go.

How an order works

Find the video

Instagram, TikTok, a YouTube Short or a full-length YouTube video. If it plays in a browser, it works here.

Copy the share link

Use the app's own Share or Copy link button. The address in your browser bar works too.

Paste it into the order form

Down this sheet under Order form. Tick how you want the file delivered.

Copy your receipt

The form prints one line at the bottom. That line is your order. Press Copy.

Paste it into Terminal

Setup, once

Four steps, then you never do this again.

Install Homebrew

Open Terminal. Press Cmd+Space, type "Terminal", press Enter. Paste this line and press Enter.

Paste into Terminal
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
It will ask for your Mac login password. Nothing appears while you type. No dots, no stars, nothing at all. The screen is not frozen and your keyboard is not broken. Type it, press Enter, then press Enter again when it asks to continue.

When it finishes, the last thing it prints is a block headed ==> Next steps: containing two commands. They are not optional and they are not the same on every Mac, so run the two it printed, not the two printed here. They put Homebrew on your PATH.

Terminal prints something like this
==> Installation successful! ==> Next steps: - Run these commands in your terminal to add Homebrew to your PATH: echo >> /Users/you/.zprofile echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> /Users/you/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

Copy the bold lines out of your own Terminal one at a time, paste each one, press Enter. Nothing visible happens, which is correct.

Install ffmpeg and pipx

Paste into Terminal
brew install ffmpeg pipx

ffmpeg merges the separate video and audio streams that these sites serve, and handles any conversion. pipx installs yt-dlp in its own isolated environment so it cannot break anything else.

Terminal prints something like this
==> Fetching ffmpeg ==> Pouring ffmpeg--7.1.arm64_sonoma.bottle.tar.gz ==> Pouring pipx--1.7.1.arm64_sonoma.bottle.tar.gz 🍺 /opt/homebrew/Cellar/ffmpeg/7.1: 285 files, 51.6MB

This one takes a few minutes and prints a lot. A wall of text is normal. What you want at the end is the beer glass, not an error.

Install yt-dlp

Paste into Terminal
pipx install "yt-dlp[default,curl-cffi]" pipx ensurepath

The curl-cffi part is the piece that matters and the piece most guides leave out. It lets yt-dlp reproduce a real Chrome network fingerprint. Without it, TikTok answers every request with 403 Forbidden no matter which other flags you use.

Terminal prints something like this
installed package yt-dlp 2025.09.05, installed using Python 3.13.1 These apps are now globally available - yt-dlp done! ✨ 🌟 ✨

If it says yt-dlp is already installed, add --force to the front command and run it again.

Restart Terminal and check

Quit Terminal completely with Cmd+Q, then open it again. This is not optional; the new commands are not on your path until you do.

Paste into Terminal
yt-dlp --version yt-dlp --list-impersonate-targets

Two answers come back. The first is a version number, written as year, month, day. The second is a table of the browsers yt-dlp can pretend to be. Both need to look like this.

Terminal prints something like this
2025.09.05 ← the version. Four digits, month, day. Client Version OS Source ------ ------- ------- --------- chrome 131 windows curl_cffi chrome 131 macos curl_cffi safari 18.0 macos curl_cffi edge 101 windows curl_cffi

The version number is a date. If yours reads something like 2024.03.10, it is over a year old and downloads will start failing. Run pipx upgrade yt-dlp.

The browser table is the important one. You want rows in it, with curl_cffi in the Source column and chrome and safari among the clients. If the table is empty, or the command errors, the curl-cffi part did not install and TikTok will return 403 Forbidden. Run step three again with --force.

Monthly check

Once a month, check the yt-dlp inside your Mac. One command opens a small panel that does it for you.

These sites change how they serve video every few weeks, and yt-dlp ships fixes within days. A copy more than a month or two old is the single most common reason downloads stop working. Checking it monthly means you find out before a download fails, not after.

Paste into Terminal
snag dash

A page opens in your browser. It shows how old your yt-dlp is, with a coloured flag: green means fresh, blue means worth upgrading, red means this is probably your problem. One button upgrades it. Another runs a self-test that downloads a 19-second video, checks the file came out in the right codec, and deletes it again. It also lists what you downloaded recently.

This panel really can run things, because it is a small server on your own Mac rather than a page on the internet. It listens on 127.0.0.1 only, nothing outside your Mac can reach it, and closing the Terminal window stops it.

If you would rather not open the panel

This one line does the upgrade on its own. It is the same thing the green button does.

Paste into Terminal
pipx upgrade yt-dlp

How often

Once a month. Put it in your calendar, or run it the first time a download looks wrong.

What the flag means

  • Green: under 30 days. Fine.
  • Blue: 30 to 60 days. Upgrade it.
  • Red: over 60 days. This is your problem.

When it breaks

Find the message you saw. Each one has one fix.

Do this first, whatever the message says

Run pipx upgrade yt-dlp in Terminal, then try your download again. This alone fixes most failures. Only work through the list below if the problem survives an upgrade.

HTTP Error 403: Forbidden

What it means. The site refused to answer. It could not tell that the request came from a real browser.

The fix

The Chrome-impersonation support is missing. Check it by running yt-dlp --list-impersonate-targets. If that prints an empty table, or errors, run the line below and try again.

Paste into Terminal
pipx install --force "yt-dlp[default,curl-cffi]"

Login required, or Please wait a few minutes before you try again

What it means. Instagram will not show the video to someone who is not signed in.

The fix

Sign into Instagram in Chrome. Then quit Chrome completely with Cmd+Q, not just closing the window. macOS will not let Snag read your login while Chrome is open. Then run your command again. The order form ticks Use my Chrome login for Instagram and TikTok links automatically, so the command already carries it.

ERROR: Unable to extract

What it means. The site changed how its pages are built, and yt-dlp has not caught up on your machine.

The fix

Upgrade yt-dlp. This is the upgrade case at the top of this list, almost every time.

command not found: snag

What it means. Snag is installed, but your Terminal does not know where to look for it.

The fix

Paste the line below, then quit Terminal with Cmd+Q and open it again. The second part matters; the change does not take effect until Terminal restarts.

Paste into Terminal
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.zshrc

It downloaded a whole playlist instead of one video

What it means. Your YouTube link had &list= in it, and Whole playlist was ticked on the order form.

The fix

Untick Whole playlist and build the command again. With it off, a link carrying a playlist gets you only the one video you were watching.

The file plays fine but my editing software struggles with it

What it means. You have an AV1 or VP9 file. Browsers play those easily. Premiere and Resolve decode them in software, so scrubbing becomes unusable.

The fix

Use Ready to edit on the order form. That restricts the download to H.264, which every editor handles natively, and it needs no conversion. It tops out at 1080p, because that is where H.264 stops on YouTube. If you need 4K that edits, use 4K, slow instead, which downloads the best stream and re-encodes it. That takes real minutes.

First move

Upgrade yt-dlp. It fixes most failures.
