# Snag logo

A fish hook on a blue glass tile. The wordmark is "SNAG" in capitals, centred on the tile.

| File | Use |
|---|---|
| `snag-lockup.svg`, `snag-lockup@2x.png` | Mark and wordmark together, on light backgrounds |
| `snag-mark.svg`, `snag-mark-512.png` | The mark alone, with room for its soft shadow |
| `snag-icon.svg`, `snag-icon-1024.png` | Square app icon and favicon |
| `apple-touch-icon.png` | 180px icon for iPhone home screens |
| `snag-wordmark.svg` | Wordmark alone, ink `#1d1d1f` |
| `snag-wordmark-white.svg` | Wordmark alone, white, for dark backgrounds |

Colours: tile runs from `#5eb1ff` to `#0a5bd6` with a `#0b4fb8` base, which matches the site's system blue `#0071e3`. The hook is white with a faint blue shade.

Keep the mark at 16px or larger. In the lockup the capitals are 38% of the tile's height, centred on it.

## Font

The wordmark is set in **Unbounded** Bold (weight 700, capitals, tracking +0.02em) by NaN, released under the SIL Open Font License 1.1. The letters are converted to outlines in these files, so no font file is needed to use them. To set new text in the same face, download Unbounded from Google Fonts.
