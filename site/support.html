Support Snag

Snag is free and will stay free. If it saved you time, you can buy me a coffee.

I'm Bagas, a post production manager. I wrote Snag because I kept needing reference clips from Instagram and TikTok that would drop straight into Premiere, and every downloader site I tried capped the quality, added a watermark or broke within a week.

Keeping it working is the ongoing part. Sites change how they serve video, flags stop working, and this site and the script need testing again each time. A tip pays for that time.

Nothing changes if you don't. There is no paid version, no locked feature and no reminder in the script. You get the same Snag either way.
