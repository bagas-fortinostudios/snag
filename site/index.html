What this actually is

A shell script that picks the right arguments for two programs you already trust. It downloads nothing itself.

yt-dlp does one hundred percent of the fetching. ffmpeg does one hundred percent of the merging, transcoding and audio extraction. Snag is about three hundred lines of shell that decide which flags to hand them, based on the link you pasted. Delete it tomorrow and you lose nothing but typing.

What it genuinely adds is judgement rather than capability: the correct sort order so that asking for maximum resolution does not quietly hand you 1080p, browser impersonation only on the sites that need it, and per-link isolation so one dead link does not kill the other nine in a batch.

This page cannot touch your computer

Every button here copies text to your clipboard. You paste it into Terminal yourself, read it first if you like, and press Enter. A web page in a browser tab cannot run commands on your Mac, cannot see your Downloads folder, and cannot test a download. Any site that claims otherwise is doing the work on their server, with your link, at their quality cap.

Nothing you paste here leaves your machine. There is no queue and no quality limit because there is nobody in the middle to impose one.

The honest reason not to use this: you have to open Terminal once, and follow four steps that involve typing your Mac password into a window that shows nothing while you type. If that is a dealbreaker, close this tab. There is no version of this tool that avoids it, and the sites that promise otherwise are selling your attention to advertisers instead.

Setup, once

Four steps, then you never do this again.

Install Homebrew

Open Terminal. Press Cmd+Space, type "Terminal", press Enter. Paste this line and press Enter.

Paste into Terminal
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
It will ask for your Mac login password. Nothing appears while you type. No dots, no stars, nothing at all. The screen is not frozen and your keyboard is not broken. Type it, press Enter, then press Enter again when it asks to continue.

When it finishes it prints a section called "Next steps" with two more commands. Run the exact two it gives you. They add Homebrew to your PATH.

Install ffmpeg and pipx

Paste into Terminal
brew install ffmpeg pipx

ffmpeg merges the separate video and audio streams that these sites serve, and handles any conversion. pipx installs yt-dlp in its own isolated environment so it cannot break anything else.

Install yt-dlp

Paste into Terminal
pipx install "yt-dlp[default,curl-cffi]" pipx ensurepath

The curl-cffi part is the piece that matters and the piece most guides leave out. It lets yt-dlp reproduce a real Chrome network fingerprint. Without it, TikTok answers every request with 403 Forbidden no matter which other flags you use.

Restart Terminal and check

Quit Terminal completely with Cmd+Q, then open it again. This is not optional; the new commands are not on your path until you do.

Paste into Terminal
yt-dlp --version yt-dlp --list-impersonate-targets

You want a version number from the first, and a list of Chrome and Safari entries from the second. If that list is empty, the curl-cffi part did not install. Run step three again.

Before you start

Allow about 10 minutes. You will need your Mac login password for step 1.

Health check

One command opens a small control panel, running on your own Mac.

Paste into Terminal
snag dash

It tells you how old your yt-dlp is, upgrades it, and runs a self-test that downloads a 19-second video, checks the codec came out right, and deletes it again. It also lists what you downloaded recently.

This one really can run things, because it is a small server on your machine rather than a page on the internet. It listens on 127.0.0.1 only, nothing outside your Mac can reach it, and closing the Terminal window stops it.

Why it matters

These sites change often. A yt-dlp more than a month or two old is the usual reason downloads stop working.

When it breaks

It will break. These sites change constantly and yt-dlp ships fixes within days.

Try this first. It fixes most of them.

A yt-dlp more than a month or two old is the single most common cause of "it stopped working yesterday". Run this before you debug anything else, including anything below.

Paste into Terminal
pipx upgrade yt-dlp

HTTP Error 403: Forbidden, on TikTok

Snag already passes --impersonate chrome on every TikTok link, so if you still see this, the impersonation support is missing rather than unused. Check with yt-dlp --list-impersonate-targets. An empty list means you need pipx install --force "yt-dlp[default,curl-cffi]".

Login required, or rate limited, on Instagram

Tick Use my Chrome login on the order form. Be signed into Instagram in Chrome, and quit Chrome before you run the command. macOS will not let yt-dlp read the cookie database while Chrome holds it open.

Unable to extract

The site changed the structure of their pages. This is the upgrade case above, almost every time.

command not found: snag

Your shell cannot see ~/bin. Add export PATH="$HOME/bin:$PATH" to ~/.zshrc, then quit Terminal with Cmd+Q and open it again.

It downloaded an entire playlist

That was a YouTube link carrying &list= in it. Snag passes --no-playlist by default, so this only happens if you ticked Whole playlist.

Why "best H.264" is not the same as "highest resolution"

YouTube stores several versions of the same video. H.264, the codec every editing program handles natively, usually stops at 1080p. Anything above that is VP9 or AV1, which your browser plays happily but which Premiere and Resolve decode in software, so scrubbing becomes unusable.

The trap is the sort order. Asking yt-dlp to sort by codec before resolution silently caps you at 1080p forever. Sorting by resolution against a list already filtered to H.264 is what actually gives you the best file you can edit. This tool got that wrong in its first version, which is why it is written down here.

First move

Upgrade yt-dlp. It fixes most failures.

Shortcut

snag dash does the upgrade and the test for you. See Health check.
