Set up Snag

Set up once.
Then it is one line.

Five steps in Terminal, about 10 minutes. Each one shows what you should see when it worked.

Before you startHave your Mac login password ready for step 1.

  1. Install Homebrew
  2. Install ffmpeg and pipx
  3. Install yt-dlp
  4. Restart and check
  5. Install Snag

1. Install Homebrew

Open Terminal: press ⌘ Space, type Terminal, press Enter. Paste this line and press Enter.

Paste into Terminal
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

It asks for your Mac login password, and nothing appears while you type. No dots, no stars. The screen is not frozen. Type it, press Enter, then press Enter again when it asks to continue.

When it finishes, it prints a block headed Next steps with two or three commands. They are not optional, and they differ from Mac to Mac, so run the ones your Terminal printed, not the ones below. They put Homebrew on your path.

Terminal prints something like this
==> Installation successful!

==> Next steps:
- Run these commands in your terminal to add Homebrew to your PATH:
    echo >> /Users/you/.zprofile
    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> /Users/you/.zprofile
    eval "$(/opt/homebrew/bin/brew shellenv)"

Copy each bold line from your own Terminal, paste it, press Enter. Nothing visible happens, which is correct.

2. Install ffmpeg and pipx

Paste into Terminal
brew install ffmpeg pipx

ffmpeg joins the separate video and audio streams these sites serve, and handles any converting. pipx installs yt-dlp in its own space, so it cannot break anything else on your Mac.

Terminal prints something like this
==> Fetching ffmpeg
==> Pouring ffmpeg--7.1.arm64_sonoma.bottle.tar.gz
==> Pouring pipx--1.7.1.arm64_sonoma.bottle.tar.gz
🍺  /opt/homebrew/Cellar/ffmpeg/7.1: 285 files, 51.6MB

A few minutes and a wall of text is normal. Done when you see the beer glass, not an error.

3. Install yt-dlp

Paste into Terminal
pipx install "yt-dlp[default,curl-cffi]"
pipx ensurepath

The curl-cffi part is the piece most guides leave out. It lets yt-dlp present itself like a real Chrome browser. Without it, TikTok answers every request with 403 Forbidden, whatever else you try.

Terminal prints something like this
installed package yt-dlp 2026.08.19, installed using Python 3.13.1
  These apps are now globally available
    - yt-dlp
done! ✨ 🌟 ✨

If it says yt-dlp is already installed, run the first line again with --force after install.

4. Restart Terminal and check

Quit Terminal completely with ⌘ Q, then open it again. This is not optional: the new commands are not found until you do.

Paste into Terminal
yt-dlp --version
yt-dlp --list-impersonate-targets
Terminal prints something like this
2026.08.19      ← the version, written as a date

Client   Version  OS       Source
------   -------  -------  ---------
chrome   131      windows  curl_cffi
chrome   131      macos    curl_cffi
safari   18.0     macos    curl_cffi
edge     101      windows  curl_cffi

The version is a date. If yours reads something like 2025.03.10, it is over a year old and downloads will fail. Run pipx upgrade yt-dlp.

The table is the important part. You want rows with curl_cffi in the Source column, and chrome and safari among them. If it is empty or errors, the Chrome support did not install and TikTok will return 403 Forbidden. Run step 3 again with --force.

5. Install Snag

This writes one file, ~/bin/snag, makes it runnable, and adds one line to ~/.zshrc if your path needs it. Nothing else.

Do not paste an installer from a website you have not read. The whole script, all lines, is on the Source page. Paste it into ChatGPT or Claude and ask what it does before you run this.
